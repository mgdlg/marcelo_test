Rounded keyword chips for skill clusters, tech stacks, and filters. Wrap a group in `TagList` for consistent spacing.

```jsx
<TagList>
  <Tag>ArcGIS Pro</Tag>
  <Tag>NDVI / NWI</Tag>
  <Tag active>UAV photogrammetry</Tag>
</TagList>
```

`active` paints the selected/emphasis state. Tags lift 1px on hover. Keep labels short — single terms or two-word phrases.
