Urban Park Biodiversity Monitoring Framework

Built a monitoring toolkit for urban parks that blends citizen science observations with GIS analytics to track biodiversity over time.

Focus: Citizen science, urban ecology Tools: iNaturalist, R, ArcGIS StoryMaps Outputs: Monitoring framework, data dashboards

Framework Highlights

Established protocols for data collection, validation, and reporting to help park managers understand biodiversity trends.

Data Sources

  • Integrated iNaturalist and GBIF records.
  • Mapped sampling intensity across park zones.
  • Built species richness dashboards for decision-makers.

Results

Delivered a repeatable template for urban biodiversity monitoring across multiple municipalities.
